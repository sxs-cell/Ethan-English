# Ethan英语 · 考研英语作文学习网站

简约的考研英语一/二大小作文学习平台，纯 HTML/CSS/JS 实现，零外部依赖。

## 快速开始

### 方式一：直接打开（最简单）
双击 `index.html` 即可在浏览器中使用。所有功能均为本地运行，无需联网、无需安装。

> 注意：此方式下「AI 精批」需配置 API Key 且依赖服务商允许浏览器跨域；「本地批改」「词汇库」「范文库」「打卡勋章」等功能完全可用。

### 方式二：静态托管
把整个目录上传到任意静态托管（GitHub Pages / Vercel / 腾讯云 COS 静态网站等）即可上线。

### 方式三：带 AI 批改后端（推荐，需 Node.js 18+）
```bash
export AI_API_KEY=sk-你的Key        # DeepSeek / OpenAI 的 Key
export AI_BASE_URL=https://api.deepseek.com   # 可选，默认 DeepSeek
export AI_MODEL=deepseek-chat                 # 可选
node server.js
```
浏览器打开 `http://localhost:3000`，在「作文批改 → AI 配置」中：
- Base URL 填 `http://localhost:3000`
- API Key 留空（Key 由服务端注入，不再暴露在前端）

## 功能清单

| 页面 | 功能 |
|------|------|
| 首页 | 学习闭环、栏目入口、数据统计 |
| 范文库 | 6 篇模板示范 + 8 篇真题范文解析（含审题立意/结构拆解/亮点句型/主题词）+ 41 道真题 |
| 词汇库 | 七大主题 60 词，搜索/筛选/生词本收藏（本地存储） |
| 写作技巧 | 三段式框架、七种论证方案、万能句、评分标准 |
| 作文批改 | 本地规则批改 + 可配置 AI 精批 + 批改历史 + 打卡勋章 |
| 资源下载 | 7 份备考 PDF（含答题卡） |

## 数据说明
- 生词本、批改历史、打卡天数、勋章、AI 配置均保存在浏览器 localStorage，不上传服务器。
- 清除浏览器缓存会清空这些本地数据。
